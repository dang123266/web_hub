# Link hay
Mỗi link là một file `items/<id>.md`: tên, loại (GitHub / Web / Công cụ...), thẻ, `summary` giới thiệu và một nút trong `files`:
    files:
      - label: "Mở trên GitHub"
        url: "https://github.com/..."
Thêm nhanh: `npm run new-item -- "Tên dự án" --module links --type GitHub --tags "ai, công cụ"`
